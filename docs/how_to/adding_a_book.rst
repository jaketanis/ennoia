Adding a book
=============

1. Open Ennoia and then log in. 

2. Click **Add**. Ennoia opens a window for you to add a book.

3. Type the **Title** of a book you are reading.

4. Type the **Author** of the same book.

5. In **Notes**, type your thoughts on the book.

5. Click **Add**. Ennoia displays the book.
